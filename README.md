# ReCaption 🖼️🤖

ReCaption is an AI-powered image captioning application that uses a pretrained BLIP model from Hugging Face Transformers to automatically generate natural-language descriptions of images.

## Features

- Generate captions for images using AI
- Uses Salesforce BLIP image-captioning model
- Runs locally using PyTorch
- Supports image processing with Pillow
- Uses Hugging Face Transformers

## Tech Stack

- Python
- PyTorch
- Hugging Face Transformers
- BLIP
- Pillow
